# Política de Segurança

## Reportando uma vulnerabilidade

**Não abra uma issue pública.** Use o [relato privado de vulnerabilidades](https://github.com/rogerinhoduraes/oneword/security/advisories/new) do GitHub.

Inclua: descrição, passos para reproduzir, impacto e versão afetada. Responderemos o quanto antes.

## Versões suportadas

Apenas a versão mais recente publicada na App Store recebe correções de segurança.
