Perguntas frequentes

O que é leitura RSVP?

RSVP (Rapid Serial Visual Presentation) mostra o texto uma palavra por vez, no mesmo ponto da tela. Isso elimina os movimentos dos olhos entre palavras e permite ler mais rápido.

O que é o ORP?

ORP (Optimal Recognition Point) é a letra de cada palavra onde o olhar a reconhece mais depressa. O OneWord alinha essa letra ao centro e a destaca em vermelho.

O OneWord é gratuito?

Sim. Todos os recursos são gratuitos, e o app é mantido por anúncios.

Quais formatos posso importar?

EPUB, PDF, artigos da web e texto escaneado pela câmera com OCR.
