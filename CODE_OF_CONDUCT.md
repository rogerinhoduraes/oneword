# Código de Conduta

Este projeto adota o [Contributor Covenant v2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, aceite críticas construtivas e não tolere assédio ou discriminação de nenhum tipo.

Para denunciar comportamento inaceitável, abra um [aviso privado de segurança](https://github.com/rogerinhoduraes/oneword/security/advisories/new) ou contate o mantenedor pelo perfil [@rogerinhoduraes](https://github.com/rogerinhoduraes). Todas as denúncias serão analisadas com confidencialidade.
